# Getting Started

SocioProphet is not open for ambient self-serve subscriptions.

The platform is being introduced through guided onboarding, institutional deployment, and public-safe documentation. That is intentional. The system is designed as a governed operational stack, not as an unbounded sign-up funnel.

## 1. Start with the right path

Pick the path that matches what you are actually trying to do.

### Learning and exploration

Use this path when the goal is to understand the architecture, the learning model, and the public-safe theory.

Read:
- [Architecture](/guide/architecture)
- [Operating Modes: Learning and Defense](/guide/operating-modes-learning-and-defense)
- [23-Topic Canon](/guide/twenty-three-topic-canon)

### Institutional deployment

Use this path when evaluating SocioProphet for an organization, program, mission-aligned institution, or governed operational environment.

Read:
- [Organizations Governance and Institutional Safety](/guide/organizations-governance-and-institutional-safety)
- [Deterministic AI and Mathematical Safety](/guide/deterministic-ai-and-mathematical-safety)

- [Organizations landing page](https://socioprophet.com/organizations/)

### Analytics, identity, and evidence

Use this path when the main interest is governed identity, merge controls, event modeling, proof artifacts, and boundary evidence.

## 2. What the public docs include

The public docs include:

- architecture
- governance
- safety boundaries
- bounded-execution model
- evidence and provenance model
- public-safe product positioning
- institutional deployment framing

## 3. What the public docs do not include

The public docs do not include:

- sensitive operator kits
- exact tactical playbooks
- exploit or persistence workflows
- high-fidelity adversary mechanics
- restricted thresholds and internals that materially raise misuse value

That line is deliberate and part of the system design.
