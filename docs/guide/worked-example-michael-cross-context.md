# Worked Example: Michael Cross-Context

This example shows why policy-constrained entity analytics matters.

A single human being can appear in multiple roles and contexts:
- patient
- parent
- citizen
- learner
- operator
- digital participant

## The risk

A technically strong linkage engine may decide those are all one perfectly mergeable identity object.

That does not mean it is safe to export or operationalize those contexts together.

## The rule

Entity Analytics should be able to:
- acknowledge shared evidence
- preserve context boundaries
- block harmful cross-context propagation
- explain the decision
