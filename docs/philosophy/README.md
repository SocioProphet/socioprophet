# Philosophy (product constitutional layer)

This directory contains doctrine-level documents that define the political, ethical, and epistemic commitments of **SocioProphet as a product and institutional surface**.

These files should stay product-scoped. They are not the right place to accumulate broad OS, workspace-controller, or agent-plane doctrine. When a concept primarily governs cross-repo orchestration, runtime substrate behavior, or workspace determinism, it should live in `SocioProphet/sociosphere` instead.

## Canonical docs

- **Liberty by Design — SocioProphet**  
  `docs/philosophy/liberty-by-design.md`

## Conventions

- Documents here should be stable, linkable, and written as acceptance criteria that downstream product specs must satisfy.
- Doctrine should map to product-facing schemas, policy guards, audit/replay tooling, moderation/governance surfaces, and evidence models.
