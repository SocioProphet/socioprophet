# Philosophy (Constitutional Layer)

This directory contains doctrine-level documents that define the political, ethical, and epistemic commitments of the SourceOS × SocioProphet federation. These are not “marketing pages”; they are constraints that should translate into enforceable protocol and policy invariants.

## Canonical docs

- **Liberty by Design — SourceOS × SocioProphet**  
  `docs/philosophy/liberty-by-design.md`  
  Defines the epistemic/constitutional thesis: distributed verification, auditable enforcement, executable education, anti-capture governance, privacy for persons / transparency for power, and curvature minimization as measurable constraint.

## Conventions

- Documents here should be stable, linkable, and written as acceptance criteria that downstream specs must satisfy.
- Where possible, doctrine should map to: (a) schemas, (b) RPC surfaces, (c) policy guards, (d) audit/replay tooling.
