# Curvature Proxy Metrics v1 (Spec Stub)

Operational proxies for informational tension / epistemic monopoly.

## Candidate metrics
- trust graph betweenness peak (monopoly curvature)
- verification replay availability variance (access curvature)
- claim vs replay divergence rate (narrative curvature)
- unverifiable removal vs refutation ratio (suppression curvature)
