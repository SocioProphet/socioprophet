# FeatureItem Component

## Purpose
Renders a single feature card used in the landing page “about” section.

## Key Files
- `FeatureItem.tsx` – Accepts `heading` and `description` props to display content.
- `styles.tsx` – Styled-components defining typography and responsive layout rules.

## Responsibilities
- Display a section heading in uppercase with letter spacing.
- Render descriptive copy with responsive sizing adjustments.

## Notes
- This component is intentionally content-agnostic; it does not own its copy or data.
