# Logo Component

## Purpose
Displays the primary SocioProphet logo in the hero section.

## Key Files
- `Logo.tsx` – Renders the logo image from `public/images`.
- `styles.tsx` – Styled-components for layout and responsive sizing.

## Responsibilities
- Provide a consistent logo size in desktop layouts.
- Scale down the logo image for smaller screens.

## Notes
- The asset is imported from `public/images/mothership-logo.png` so Webpack can bundle it.
