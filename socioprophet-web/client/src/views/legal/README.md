# Legal Views

## Purpose
Contains the legal policy pages displayed in the application.

## Key Files
- `Terms.tsx` – Full Terms of Use copy for SocioProphet.
- `Privacy.tsx` – Privacy Policy copy and supporting links.
- `styles.tsx` – Shared styled-components for headings, descriptions, lists, and links.

## Responsibilities
- Render static policy content with consistent typography.
- Provide navigation back to the landing page (`/`).

## Notes
- Copy is embedded directly in the components; changes should be coordinated with legal review.
